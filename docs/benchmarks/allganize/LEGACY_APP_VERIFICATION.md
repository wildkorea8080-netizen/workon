# 기존 AI 비서 점검 결과

2026-10-30 연결된 시험 DB와 로컬 현재 소스를 기준으로 확인했다. 운영 로그인 세션을 사용하는 브라우저 E2E 시험과 구분한다.

| 범위 | 실측 결과 |
| --- | --- |
| 기존 비서 장부 | 공식 비서 42개. 기관별 동일 이름 포함 23개 이름. 공개 활성 대화형 비서 41개 |
| 비서별 모델 응답 | 41개 모두 저장된 시스템 프롬프트와 정책에 맞는 모델로 실제 응답 반환. 오류·빈 응답 0개 |
| 제외 | 비공개 외부 링크형 비서 1개. 사용자 노출 대상이 아니므로 응답 시험 제외 |
| 설정 | 42개 능력 설정 유효. 현재 판 누락·기관 미연결·문서가 있는데 검색 능력이 꺼진 비서 0개 |

| ReadLayer 실제 연결 | 독립 가상 보관함에서 업로드·읽기·관련 근거/위치 반환·무관 질문 거절·삭제 및 삭제 확인 통과 |
| 공공데이터 실제 연결 | 법령 검색·조문·판례, KOSIS 검색·데이터, 나라장터 공고, DART 공시·기업개황 모두 통과 |
| 실제 스트리밍 도구 루프 | Claude → 법령 검색 → 조문 조회 → 출처 3건 수집 → 최종 답변 생성 통과 |

비서별 응답 시험은 기존 프롬프트와 가상 점검 질문의 외부 Claude API 전송을 사용자가 명시적으로 승인한 후 진행했다. 실제 기관 문서·기존 대화는 전송하지 않았다. 비서별 시험에서 DB는 읽기만 하고 대화·사용량 행은 만들지 않았다. 별도 API 비용이 발생하며 모델 응답 시험의 토큰 합계는 입력 13,479, 출력 4,517이다.

## 해석과 남은 검증

이번 확인 범위에서는 기존 기능의 회귀 실패나 비서별 모델 연결 오류가 발견되지 않았다. 비서별 가상 질문은 업무 안내를 요청해 기본 응답을 확인한 것이며, 모든 비서의 전문 업무 결과 정확성이나 첨부·다운로드 성공을 증명하지 않는다. 또한 로컬 환경변수와 연결 DB를 사용한 시험이므로 운영 환경변수와 로그인 경로까지 같은 결과라고 보장하지 않는다.

로그인한 운영 화면에서 앱 선택 → 질문/파일 첨부 → 응답 → 결과 파일 다운로드의 전체 과정은 미검증이다. 실제 문서에 대한 답변 품질과 자료가 없는 비서의 전문성은 별도 업무 시나리오로 확인해야 한다.

- 재실행: `npx tsx scripts/legacy-app-audit.mjs` (설정 조회만)
- 모델 응답 재실행: `npx tsx scripts/legacy-app-audit.mjs --live` (승인된 외부 프롬프트 전송 및 API 비용 발생)
- 비서별 결과: [legacy-app-audit.json](./evidence/legacy-app-audit.json)

애플리케이션 실행 코드는 변경하지 않았다. 점검 스크립트와 결과 문서만 추가했다.

## 발견 사항

1. **재개 가능 여부가 앱 단위**다. 파일 첨부를 켠 앱은 파일을 붙이지 않은 실행도 재개 대상이 아니다(`capabilities`가 비어 있을 때만 `app_inputs` 저장). → **같은 날 실행 단위로 고쳤다**: 켜진 능력이 첨부 읽기뿐이고 그 실행에 파일이 없으면 입력을 저장하고 재개를 허용한다(`isInputOnlyRun`). 재개 대기 중 파일을 붙이면 화면이 버튼을 끄고 이유를 보이며 서버도 409로 거절한다. 시험: `prepare-preflight`(파일 없는 재개 허용·파일 붙인 재개 거절)·`stream-turn`(입력 저장 세 경우). 브라우저로는 다시 확인하지 않았다(실제 모델 호출이 필요해 비용이 든다).
2. 앱 라이브러리 카드의 별 버튼은 같은 좌표에 두 번 눌러도 한 번만 반영됐다(두 번째는 목록이 다시 그려지며 다른 요소로 이동). 사용자 조작에서는 문제 아님.
3. 로컬 스택 스크립트 `dev-e2e.cjs`에 `LIVE_MODEL` 마커 파일로 실제 모델을 켜는 분기와 `NEXT_PUBLIC_WORKSPACE_HOME=apps`를 더했다(scratchpad, 저장소 밖).

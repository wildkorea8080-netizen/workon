## 알리웍스 사용자 화면(가이드 기준)

- **왼쪽 사이드바 하나에 다 있다.** 위에서부터 프로젝트 이름(로고)·접기 단추 → `+ 새 대화` → 홈·전체 앱·문서함 → **대화 기록**(오늘·날짜·지난 30일로 묶음, 제목은 첫 답변으로 자동 요약) → 아래쪽 `Alli works 관리하기`(대시보드 권한자만)·업데이트 소식·사용자 가이드·프로필.
- **위쪽 머리 막대가 없다.** 회사 이름·로고는 사이드바 맨 위에.
- **홈은 입력창이 주인공.** 가운데 큰 안내 문구(프로젝트마다 바꿀 수 있음) → 큰 입력창('필요한 업무를 편하게 입력해보세요') → 입력창을 누르면 **추천 질문**이 펼쳐짐 → 그 아래 카테고리(즐겨찾기·추천…) 고르기와 **앱 카드 3장 넘기기**(카드에 대화형·답변형 표시) → `전체 앱 보기`.
- **앱을 고르지 않아도 바로 묻는다.** 홈 입력창에 그냥 쓰면 문서 검색 대화가 된다. 입력창 아래 단추로 앱·파일 올리기·**검색 범위**(공용·개인 문서함에서 참조할 문서·폴더 고르기)를 고른다.
- **대화 화면은 세 칸.** 왼쪽 사이드바 · 가운데 대화 · 오른쪽 **답변 근거 문서** 창(원본 PDF를 쪽 단위로 그려 근거 문장을 노란색으로 칠함, 쪽 이동·확대·내려받기). 답 속 `[1]`이 근거를 가리킨다.
- 디자인 설정: 회사명·로고·**테마 색**(기본 보라)·카테고리 이름·아이콘·순서를 관리자가 바꾼다. 관리 기능은 별도 '대시보드'(앱 마켓·앱 관리·멤버·대화·문서·지식 베이스·통계·설정).

## 웍스AI 사용자 화면(공개 이용가이드 기준)

- 근거: [docs.wrks.ai](https://docs.wrks.ai/) — [에이전트(대화) 이용 방법](https://docs.wrks.ai/user-guide/agents)(2026-11-05 갱신)·[우리 회사 에이전트](https://docs.wrks.ai/user-guide/company-assistants)·[2026년 한눈에 보기](https://docs.wrks.ai/2026-ai)·릴리스 노트 '2026.11.04 11월 1주차'(사이드바 개편)·'에이전트 홈과 대화 화면이 새로워졌어요'. 가이드 캡처와 설명만 봤고 로그인 화면은 보지 않았다. 2026-11-06에 받아 읽었다.
- **2026-11-04에 사이드바를 개편했다** — "화면 위쪽에 있던 메뉴를 **왼쪽 사이드바로 모았다**". 지금 구성: 로고·접기 단추 → **업무**(에이전트·워크플로우·스킬·웍스 드라이브·AI 도구 11개, 자주 쓰는 도구는 '사이드바에 고정') → **최근 대화**(오늘·어제·지난 7일·달 단위, ⋯ 메뉴로 이름 바꾸기·삭제) → 워크스페이스 사용량 막대 → 프로필. 접으면 메뉴가 아이콘으로 남는다. **오른쪽 위에는 관리자·테마·언어·알림 단추만** 남았다(머리 막대 메뉴 없음).
- 예전 위쪽 메뉴의 'AI 대화'(→'에이전트')도 사이드바 '업무 > 에이전트'로 옮겼다. 그보다 앞서(2025) 대화 목록을 **어두운 배경에서 밝은 배경**으로 바꾸고 접을 수 있게 했다.
- **에이전트 홈 = 입력창 중심.** 공지 줄 → '지금 궁금하거나 필요한게 있으세요?' → 큰 입력창(+ 도구·모델 고르기·생각 깊이·음성) → '개인정보 등 민감정보는 입력·업로드하지 마세요' → AI 도구 단추 줄(이미지·회의록·슬라이드·문서 번역·문서 작성…) → **'에이전트를 골라 일을 맡겨주세요.'**(웍스 공식·회사·워크스페이스·나만의 에이전트 탭 + 분야 알약 + 카드 3열, 별 즐겨찾기) → 대화 예약.
- **에이전트를 고르지 않아도 입력창에 바로 보내면 대화가 시작된다.** 카드를 누르면 그 에이전트와 대화.
- **대화 화면**: 위쪽 메뉴를 줄여 답이 넓게, 도구를 쓴 과정은 답 위 한 줄로 묶고 누르면 단계별로, 입력창은 한 줄 + 연결된 도구 이름, 답한 모델·시각은 답 끝에.

## 결론


화면의 부품(새 대화·날짜별 대화 기록·가운데 대화·오른쪽 근거 창·카드)은 비슷하지만 **같은 구성은 아니다.** 알리웍스와 웍스AI는 둘 다 **'왼쪽 사이드바 하나(메뉴 + 대화 기록) + 입력창 중심 홈'** 으로 모였다 — 웍스AI는 바로 이번 주(2026-11-04) 위쪽 메뉴를 걷어 내고 이 꼴로 바꿨다. WORKON은 '머리 막대 + 업무 메뉴 + (대화에서) 대화 목록 둘째 칸 + 업무 앱 중심 홈'이다.

손볼 만한 후보(결정 전):
1. `/chat` 첫 화면에서 비서를 고르지 않고 바로 묻기 — 기본 비서(예: 기관 공통 문서 비서)로 보내기. 어느 비서를 기본으로 할지가 먼저다.
2. 왼쪽 두 줄 정리 — 두 서비스처럼 **최근 대화를 업무 메뉴 아래로 합쳐 사이드바 하나로**(가장 근본적), 또는 대화 화면에서 업무 메뉴를 아이콘만 남기고 접기. 사이드바 접기(아이콘으로 남김)는 둘 다 있다.
3. 기관별 테마 색 — 브랜딩(0020)에 색 칸 하나. 공공기관 CI 요구와 맞닿는다.

## 반영(2026-11-06)

- 2번을 했다 — 업무 틀 사이드바 하나에 업무 메뉴와 **최근 대화**(날짜 묶음·검색·이름 바꾸기·공유·삭제)를 함께 두고, 대화 화면의 대화 목록 둘째 칸을 없앴다. 모든 업무 화면에서 최근 대화가 보인다. 위쪽 머리 막대·사이드바 접기·입력창 중심 홈·비서 없이 묻기는 그대로 남은 차이다.
- 1번도 했다 — `/chat` 첫 화면 입력창에 바로 물으면 마지막으로 대화한 비서(없으면 첫 공식 비서)가 답하고, 입력창 아래에 '답할 비서: 이름'을 보인다. 이때 첫 화면에 적은 질문이 버려지던 결함(보내면 화면만 바뀜)도 고쳤다.

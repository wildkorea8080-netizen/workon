# 비서 선택을 유지하는 업무 시작 흐름

2026-10-29. 앱 라이브러리의 일반 비서 카드에서 규정 확인·보고서 작성·민원 회신으로 이동하는 링크를 추가했다. 기관에서 업무 사용이 켜져 있고 해당 업무가 가용한 경우만 제공한다. 링크 이동만으로 작업·모델 호출을 만들지 않는다.

작업 시작 화면은 URL의 비서 ID를 기존 권한 API가 반환한 가용 비서 목록과 비교해 선택한다. 중지·삭제·외부 링크 비서를 제외하고 중복을 제거한다. ID를 확인하지 못하면 다른 비서나 기본 지침을 선택하라는 안내를 표시한다. 문서함 검색은 자동 선택하지 않고 직원이 따로 체크한다. 최종 저장 권한은 기존 서버 검사를 그대로 거친다.

업무·비서 목록을 불러오는 중에는 저장을 막고 상태를 표시한다. 잘못된 업무 주소, 업무 목록·양식 불러오기 오류에는 안내·재시도·앱 목록 복귀를 제공한다. 업무 URL 변경 시 이전 폼·양식·문서함 선택을 초기화하고, 늦게 돌아온 이전 요청이 새 화면을 덮지 않게 한다.

검증: 앱 목록·업무 이동·인증 관련 2개 파일 30개 테스트 통과. 프로덕션 빌드는 별도로 확인했다. 실제 사용자 계정으로 브라우저에서 로그인한 화면·레이아웃 검증은 아직 하지 않았다. 이번 단계는 화면 코드·동작 계약·빌드 검증이다. 운영 DB나 배포는 변경하지 않았다.

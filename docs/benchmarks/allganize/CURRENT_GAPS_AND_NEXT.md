## 이번 구현: 앱 즐겨찾기와 업무 분야 탐색

공식 가이드의 카테고리·즐겨찾기를 참고했다. 기존 AI 비서 즐겨찾기는 있었으나 새 통합 앱 목록과 문서 업무에는 연결되지 않았으므로 이 부분을 보완했다.

- 홈과 앱 라이브러리에 별 버튼·즐겨찾기 필터·업무 분야 필터·필터 초기화 추가.
- 계정별 서버 저장. 비서 즐겨찾기는 기존 favorite_agent_ids를 그대로 사용하므로 기존 대화 화면과 공유한다.
- 문서 업무 즐겨찾기는 users.favorite_workflow_keys에 별도 저장. 마이그레이션 0042.
- 저장 함수는 사용자 행 잠금과 원하는 상태 설정을 사용해 중복 등록과 새 API 내 동시 저장 덮어쓰기를 방지한다. 함수 실행 권한은 service_role에만 부여한다.
- API에서 사용자 ID를 세션에서 결정하고 기관 소속·비서 접근 권한·업무 키를 검증한다. 즐겨찾기는 실행 권한을 부여하지 않는다.
- 사용 불가/삭제된 앱은 현재 권한으로 받은 앱 목록과 교차하므로 즐겨찾기를 통해 다시 노출하지 않는다. 저장 실패는 알리고 완료로 표시하지 않는다.

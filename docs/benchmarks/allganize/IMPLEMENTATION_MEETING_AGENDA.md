# 회의 안건 초안 앱

2026-10-29. 텍스트·파일 기반 업무 초안 기능을 공공기관 회의 준비에 적용한 meeting-agenda를 추가했다. 경쟁사의 비공개 구현이나 실행 결과를 복제한 것은 아니다.

입력은 회의 제목·목적, 선택적인 예정일·장소·참석 대상, 참고 문서와 결과 양식이다. 참고 자료는 최대 3개·읽힌 원문 합계 12,000자까지 사용한다. 회의록 양식을 재사용하며 회의명 앞에 [안건 초안]을 붙인다. 안건·논의 내용 칸만 모델이 채우며, 결정 사항·향후 계획·입력하지 않은 일시는 비워 둔다. 논의 내용에는 확인 질문·사전 준비 자료·미확인 사항을 구분하도록 지시한다.

생성 칸은 사용한 원자료 ID와 연결되어야 한다. 안건에는 참고 자료 이름을 함께 표시한다. 과거 결정은 과거 사실로, 새로운 준비 요청은 제안으로 구분한다. 안건에 어떤 내용을 논의·확정하자는 표현이 있을 수 있지만, 이미 결정됐다는 회의록으로 취급하지 않는다. 회의 개최·통지·참석자 연락·일정 등록은 수행하지 않는다.

공통 문서 앱 정책에 생성 가능 칸과 주 출력 칸을 추가해, 요약·교정·번역과 다른 양식도 같은 실행기를 재사용한다. AI 수정도 앱의 허용 칸으로 제한한다.

## 검증

- 전용 로컬 PostgreSQL에 마이그레이션 40개 적용 성공.
- 앱 입력·초안 표시·생성 칸 제한·비워 둘 칸·실제 HWPX와 기존 문서 앱 회귀를 포함해 4개 파일 59개 테스트 통과.
- TypeScript·diff 공백 검사 통과.
- 실제 Claude 호출 1회로 가상 운영 개선 회의 안건을 생성. 약 15초·기록 원가 약 26원, HWPX valid.

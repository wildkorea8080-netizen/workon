# 문서 기반 FAQ 초안 앱

2026-10-29. 공개 FAQ 생성·유지관리 기능을 참고해 document-faq를 추가했다. 기존 FAQ에 자동 게시하거나 챗봇 지식으로 등록하는 기능은 아니다.

입력은 제목·이용 대상(직원/시민)·최대 질문 수(3/5/8)·중점 범위·원문 자료·결과 양식이다. 참고 문서 3개·읽힌 원문 합계 12,000자 이내에서 작성한다. 기존 보고서 양식을 사용하고 제목에는 [FAQ 초안]을 붙인다.

생성 모델은 질문별 question·answer·sourceId·quote·status를 JSON으로 반환한다. 서버는 개수·중복 질문·길이를 검사하고, grounded 답변의 인용이 지정 원자료에 실제로 존재하는지 확인한다. 모르는 문서 ID·맞지 않는 인용·잘못된 형식은 결과 파일로 저장하지 않는다. 검증된 결과만 사람이 읽는 Q/A·근거 문구로 변환해 HWPX에 넣는다.

needs_info 항목은 모델이 쓴 답변을 버리고 '[확인 필요] 자료에서 답을 확인할 수 없습니다.'로 고정한다. FAQ_NEEDS_INFO 검토 차단 항목을 만들고, 직원이 본문을 수정해도 해당 표시가 남아 있으면 차단을 유지한다. 직원은 근거를 보완하거나 항목을 제외하고 확인해야 한다. 자동 승인·게시·발송은 없다.

인용 존재 확인은 답변과 인용의 의미가 정확히 일치한다는 보증이 아니다. 적용 조건·예외·숫자·개인정보·질문 적절성은 직원이 검토해야 한다. 편집 후의 문장 의미를 자동 재검증하는 기능도 아니다.

## 검증

- 전용 PostgreSQL에 마이그레이션 41개 적용 성공.
- 실제 HWPX 생성·잘못된 인용 차단·답 없음·직원 수정 후 차단 유지와 기존 회귀를 포함해 3개 파일 53개 테스트 통과.
- TypeScript·diff 공백 검사 통과.
- 실제 Claude 호출 1회·약 11초·기록 원가 약 21원. 운영 시간·장애인 구역 답변의 원문 인용을 확인했고, 요금 질문은 확인 필요로 남았다. HWPX valid 및 FAQ_NEEDS_INFO 검토 차단 확인.

# 보고서·회신 근거에서 원문 열기

2026-10-29. 검색 근거의 문서 행 ID를 보존하고 작업실에 원문 열기를 추가했다. 공개 페이지에서 참조한 출처 추적 개념의 WORKON 독립 구현이다.

ReadLayer 근거를 현재 문서 행과 맞춘 뒤 확인한 documentId만 저장한다. 유효한 UUID만 화면에 전달하고 저장 경로·임시 주소를 근거 DTO에 섞지 않는다. 기존 근거에 문서 ID가 없으면 원문 버튼을 만들지 않는다.

GET /api/work/tasks/[id]/evidence/[documentId]/open은 다음을 확인한다.

1. 로그인·실제 소속·활성 사용자·대리 접근 제한.
2. 해당 작업의 읽기 권한과 현재 문서 판에 기록된 근거 여부.
3. 같은 기관의 문서이며 작업에서 선택한 비서의 문서인지 확인.
4. 현재 문서 공개 범위·부서 접근과 공식 비서의 활성·공개·사용 권한 재검사.
5. 통과한 경우만 60초 서명 URL로 이동. 응답은 private, no-store 및 no-referrer.

스토리지 실패 응답에는 저장 경로를 포함하지 않는다. 원문은 현재 파일이며 검색 당시 파일 판을 동결하거나 인용 위치를 자동 하이라이트하는 기능은 아니다. 저장된 발췌와 현재 원본의 차이는 화면에 안내한다.

함께 보완한 검색 범위: 공식 비서가 공개되어 있어도 그 문서의 기관·부서·공개 범위는 별도로 검사한다. 사용자가 볼 수 없는 부서 문서는 검색 대상에서 제외한다. 허용 문서가 없거나 반환 근거와 허용 문서 행이 맞지 않으면 선택 문서함 검색은 실패한다.

검증: 실제 GET 경로·작업 근거 확인·근거 메타데이터·운영 검색 제공자 관련 4개 테스트 파일 33개 통과. 세션·DB·스토리지 응답은 시험용으로 대체했다. TypeScript·diff 공백 검사 통과. 운영 스토리지의 서명 URL과 브라우저 다운로드는 아직 직접 시험하지 않았다. 운영 DB 변경·배포는 수행하지 않았다.

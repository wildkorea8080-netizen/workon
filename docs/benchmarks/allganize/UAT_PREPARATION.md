## 현재 선행 조건

후속 확인: 사용자가 연결 DB를 시험용으로 확인하고 적용을 요청해 0036~0041을 적용했다. 현재 컬럼·15종 제약·REST 점검은 통과했다. [최신 적용 결과](CONNECTED_DB_APPLIED.md). 아래 컬럼 미조회 기록은 적용 전 조사 이력이다.

현재 .env.local 연결의 REST 스키마를 0행 조회로 확인했다. work_tasks·work_sources·work_runs·work_document_versions·work_artifacts·업무 설정·설치 목록 조회는 통과했지만 work_tasks.app_snapshot은 오류 코드 42703으로 조회되지 않았다. [검사 결과](CONNECTED_DB_READINESS.json).

이 점검은 데이터 행·키·접속 주소를 출력하지 않으며 DB를 수정하지 않는다. 실제 DDL 적용 여부와 스키마 캐시 여부는 DB에서 추가 확인해야 한다. 새 워크플로우 CHECK 허용값·RPC·RLS·기관별 활성 스위치·스토리지를 검증한 것은 아니다.

0036~0041의 [검토용 SQL 묶음](evidence/DEPLOY_0036_0041_REVIEW.sql)을 준비했다. 기존 마이그레이션 여섯 개를 순서대로 한 트랜잭션에 넣은 파일이며 현재 연결 DB에서 실행하지 않았다. 적용 이력과 대상 환경을 먼저 확인해야 하며 이미 적용된 DB에 그대로 재실행하는 용도가 아니다.

각 시나리오는 새 가상 작업으로 실행하고 결과 파일을 확인한다. 실제 자료를 시험 데이터로 바꾸거나 기존 작업을 수정하지 않는다. 문서함 연결은 정식 시험 계정과 공개 공식 비서의 시험 자료가 준비된 경우에만 별도 확인한다. 실제 로그인 이후의 시나리오는 아직 실행하지 않았다.

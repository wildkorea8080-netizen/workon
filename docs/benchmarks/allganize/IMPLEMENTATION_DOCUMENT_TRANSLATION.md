# 문서 번역 앱

2026-10-29. 공개 번역 앱을 참조해 document-translation을 추가했다. 전체 앱 구현 완료가 아니다.

입력은 제목·번역 언어·문체·기관 용어 대응표·원문 파일·결과 양식이다. 한국어·영어·일본어·중국어 간체를 선택할 수 있으며 공식 문서/일반 안내 문체를 제공한다. 문서 한 개·읽힌 원문 8,000자까지 지원한다. 결과는 기존 보고서형 HWPX 양식의 개요(번역 범위·유의사항)와 주요 내용(번역문)에 저장한다. 원문 서식·레이아웃 복제는 지원하지 않는다.

요약·교정·번역의 입력 한도를 공통 정책으로 묶어 같은 필드 생성기를 재사용한다. 번역은 원문 전체·조건·예외·부정·미확정 여부를 보존하도록 지시하고, 원자료 ID와 참고 자료 이름을 연결한다. 서버는 번역 본문의 숫자값과 등장 개수를 원문과 비교한다. 날짜 순서·구분자·금액 쉼표는 바뀔 수 있지만 숫자가 추가·누락·변경되면 결과를 저장하지 않는다. 단위·통화·시간대 환산은 하지 않는다.

숫자 대조는 의미·단위·고유명사·번역 정확도 검증을 대신하지 않는다. 같은 숫자가 다른 대상에 붙는 오류는 자동 검사만으로 잡지 못한다. 숫자를 단어로 쓰거나 월 이름으로 바꾼 정당한 번역도 거부할 수 있어, 숫자형 날짜와 아라비아 숫자 표기를 사용하도록 안내한다. 직원 검토가 필요하다.

## 검증

- 전용 로컬 PostgreSQL에 마이그레이션 39개 적용 성공.
- 숫자값·개수 대조와 변경 차단, 번역 작업의 HWPX 생성, 기존 문서 앱 회귀를 포함해 3개 파일 55개 테스트 통과.
- TypeScript·diff 공백 검사 통과.
- 실제 Claude로 가상 한국어 안내문을 영어로 번역해 HWPX valid 생성. 약 5초·모델 1회·기록 원가 약 12원.
- 번역문 전체에서 날짜 2026-11-03, 시각 2 p.m., 인원 15, 금액 30,000 won과 우천 조건·추가 점검 미확정 문장을 확인했다. 가상시청 → Example City Hall 용어 대응도 반영됐다.

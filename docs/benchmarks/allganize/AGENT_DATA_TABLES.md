# 비서 데이터 파일 — 문서함의 표로 계산하기 (2026-11-26)

`CURRENT_GAPS_AND_NEXT.md`의 '자연어 BI' 첫 단계. 기관이 비서 문서함에 예산 집행 현황·사업 실적 같은 표 파일을 올려 두면, 직원이 파일을 첨부하지 않고 물어도 **표 합치기 엔진이 계산한다**(숫자는 엔진만 낸다 — S3-b 원칙 그대로). 마이그레이션 없음.

## 켜는 곳

- 비서 편집 창 → 능력 '표 합치기·집계'를 켜면 아래에 **'문서함의 표 파일로도 계산'** 칸이 생긴다. 저장 값은 `capabilities.table_merge = { agent_documents: true }`(`normalizeCapabilities` — 참·거짓 밖은 거절, 다른 값은 버림). 끄면 `{}`로 예전과 같다.
- 문서함에 표를 올렸다는 것만으로 열지 않는다 — 비서마다 켤 때만.

## 무엇을 쓰나 (`src/lib/capabilities/agent-data-files.ts`)

- 그 비서·그 기관의 문서 중 **읽힌(`ready`) 지금 판**만: 지난 판(`retired`)·지우는 중·저장소 경로 없는 행은 빼고, 판 규칙은 문서 찾기와 같은 `notCitableEditionIds`(시행 중인 새 판이 대신한 옛 판·시행일 전의 새 판 빼기).
- 형식은 표를 뽑는 것만 — 엑셀(xlsx·xlsm)·CSV·한글(hwpx·hwp). PDF·워드·파워포인트는 쓰지 않는다.
- 만든 순서(같으면 id)로 `d1`…`d20`(`MAX_DATA_FILES`) — 파일이 그대로면 턴이 바뀌어도 같은 ref.
- 범위는 **문서 찾기와 같다** — 그 비서를 쓸 수 있는 사람은 문서 찾기로 그 문서의 내용을 이미 본다(문서별 공개 범위로 따로 거르지 않음). 편집 창 안내에도 그렇게 적는다.

## 대화에서

- 프롬프트에는 **이름만** 싣는다(`[비서 데이터 파일 시작 …]` … `[비서 데이터 파일 끝]`, 제목이 있으면 `제목 (파일 이름)`, 파일에서 온 글은 첨부 개요와 같은 다듬기). 표 내용은 싣지 않는다.
- 도구 `describe_data_file { file: 'd1' }` — 그 파일의 표 id·행 수·열 이름·표 위 글(첨부 개요와 같은 꼴). 그다음 `combine_tables`의 `file`에 `d1`을 준다(첨부 `a1`과 섞어 쌓을 수 있다).
- 도구 입력은 ref뿐 — 표를 읽을 때 서버가 문서 id·비서·기관으로 다시 찾고 지금 판이 아니면 닫는다. 원본은 저장소에서 내려받아 **첨부와 같은 읽개**(`readAttachment`, 스캔 PDF 길은 쓰지 않음)로 읽는다. 한 턴에 파일마다 한 번, 못 읽은 것은 기억하지 않는다. 10MB(`DATA_FILE_MAX_BYTES`)까지.
- 첨부가 없어도 데이터 파일이 있으면 도구를 꺼낸다. 목록을 못 읽으면 도구 없이 '숫자를 짐작하지 말고 잠시 뒤 다시'(`DATA_FILES_UNREAD_NOTE`)를 싣고 운영 기록(error·database — 비서 id·오류 코드만).
- 결과 글·엑셀 계산 근거 시트·숫자 확인·사용 기록(`table_merged`, `details.data_files` — 파일 이름 없음)은 첨부 표와 같다.

## 읽어 둔 표 (2026-11-26, 마이그레이션 없음)

- 묻는 턴마다 원본을 내려받아 읽으면 큰 엑셀은 그 턴이 느리다. 한 번 읽은 표는 저장소 `data-extracts/{문서 id}.json`(gzip JSON, `documents` 버킷 — 첨부 읽은 내용과 같은 `application/gzip`)에 두고 다음부터는 그것을 쓴다(`loadAgentDataExtract`).
- 열쇠는 **문서 id**다 — 문서 행은 판이 바뀌면 새 id라(같은 id의 원본은 바뀌지 않는다) 낡지 않는다. 읽개를 바꾸면 `DATA_EXTRACT_VERSION`을 올린다(다른 판의 사본은 버리고 다시 읽음).
- 다시 해도 같은 실패(10MB 초과·읽지 못하는 파일)도 적어 두어 매번 원본을 내려받지 않는다. 저장소가 잠깐 안 된 것·뜻밖의 실패는 적지 않는다(다음에 다시).
- 사본은 원본과 같은 권한으로만 연다 — 문서 행(비서·기관·읽힘·지난 판 아님)을 먼저 확인한 뒤에만. 문서를 지우면(관리자 화면·기관 API `deleteAgentDocument`) 함께 지우고, 비서를 지워 문서 행을 치울 때(`removeAgentDocuments`)도 함께 지운다(못 지워도 막지 않음).
- **미리 읽어 두기**: 5분 실행기(`/api/cron/app-schedules`)가 데이터 파일을 켠 비서(`capabilities.table_merge.agent_documents`, 지우지 않은 것 200개 중 섞어 다섯)의 데이터 파일 가운데 아직 읽어 두지 않은 것을 한 차례에 두 개씩(25초) 읽어 둔다(`prefillDataExtracts` — 모델 호출 없음, 던지지 않음). 읽어 두었는지는 저장소 목록으로 본다(모르면 건드리지 않음).
- 대화의 표 합치기와 앱의 데이터 표 계산 조회 단계가 같은 길로 읽는다.

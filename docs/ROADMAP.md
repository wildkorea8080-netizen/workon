# WORKON v2.0 로드맵

> 현재 버전: v1.0 (BM-01 ~ BM-13 구현 완료)
> 최종 업데이트: 2026-04-24

---

## v2.0 예정 기능

### 🔗 외부 연동
- **M365 에이전트 연동** — Microsoft Teams / Outlook과 AI 비서 연결
- **SSO 연동** — 공공기관 통합인증(SAML 2.0, OAuth 2.0) 지원
- **실시간 웹 검색** — Tavily/Brave Search API 연결, 최신 정보 기반 답변

### 📁 파일 형식 확장
- **HWP 파일 지원** — 한글과컴퓨터 HWP/HWPX 파싱 및 임베딩
- **엑셀 데이터 분석** — XLSX 업로드 → Claude Code Interpreter로 데이터 분석·시각화
- **이미지 생성** — DALL·E / Stable Diffusion API 연결 (공공기관 홍보물 생성)

### 📱 접근성
- **모바일 앱** — React Native 또는 PWA로 iOS/Android 지원
- **음성 입력** — Web Speech API / Whisper API 연동

### 📊 분석 고도화
- **조직별 사용 대시보드** — 부서·직책별 사용 패턴 분석
- **AI 품질 평가** — 사용자 피드백(👍👎) 수집 및 응답 개선 루프
- **토큰 비용 관리** — 부서별 사용량 한도 설정 및 알림

### 🔒 보안·컴플라이언스
- **감사 로그 고도화** — 개인정보 접근 이력 자동 보고서
- **데이터 격리 강화** — 부서 간 완전 격리 + 암호화 at-rest
- **국정원 클라우드 보안인증(CSAP) 대응** — 보안 요구사항 체크리스트 구현

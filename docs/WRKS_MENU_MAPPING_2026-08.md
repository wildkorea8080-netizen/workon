## 1. 관리자 포털 메뉴 대조

웍스AI는 `[기업관리자]` 하나에 모여 있고, WORKON은 `/admin` 사이드바 10개로 펼쳐져 있습니다.

| 웍스AI 기업관리자 | WORKON | 상태 |
|---|---|---|
| 회사 정보 (회사명, 로고) | — | **없음** |
| 이용통계 (비서별·직원별·부서별, Excel) | 사용량 통계 (부서별) | **축 부족** |
| 결제 관리 (당월 요금, 결제 이력, 카드) | — (슈퍼관리자에만 있음) | **없음** |
| 공식 비서 관리 (카테고리·순서·노출) | 비서 관리 (공식/승인대기/반려) | **부분** |
| 직원 초대 | 사용자 관리 (초대 링크 + CSV) | ✅ |
| 워크스페이스 관리 | — (부서 계층으로 대체) | 의도적 미채택 |
| 로그인 연동 (SSO 4종) | — (Credentials만) | 없음 (장기) |
| 조직도 연동 (유료 200만원) | 부서 관리 (기본 제공) | ✅ **우위** |
| 토큰 사용량 상세 (모델별) | 사용 내역 조회 (모델·비용 열) | ✅ |
| 이용 기록 (일 8,000원 부가서비스) | 사용 로그 (기본 제공) | ✅ **우위** |
| — | 문서 관리 | WORKON 고유 |
| — | AI 프롬프트 (보고서 템플릿) | WORKON 고유 |
| — | 설정 (금지어·보안 이벤트) | WORKON 고유 |

### 1-1. 없는 것 중 공공기관에 실제로 필요한 것

**① 기관 정보 (기관명·로고)** — 우선순위 높음

공공기관은 CI 사용이 규정 사항입니다. 화면에 기관 로고가 안 나오면 "우리 시스템"으로
인식되지 않습니다. 지금 WORKON은 `NEXT_PUBLIC_APP_NAME`으로 전역 고정이라 **기관마다
다르게 표시할 방법이 아예 없습니다.** 멀티테넌트인데 브랜딩이 단일값인 구조적 공백입니다.

**② 기관 관리자용 예산 소진 현황** — 우선순위 높음

0017로 `annual_fixed` 계약과 `organization_spend_krw`를 넣었지만, **보는 화면이
슈퍼관리자에만 있습니다.** 정작 예산을 집행하는 기관 담당자가 자기 소진율을 못 봅니다.
공공기관은 분기별 집행률 보고가 있어서 이건 조회 기능이 아니라 업무 요건입니다.

`budget_alert_percent`(기본 80%) 경고도 지금은 차단 시점에만 드러납니다.

**③ 비서 카테고리·노출 순서 관리** — 우선순위 중

`agents.category`, `agents.icon` 컬럼이 **이미 있는데 관리자 화면에서 못 씁니다.**
직원용 `CreateAgentModal`에는 아이콘·카테고리 입력이 있는데 관리자용 공식 비서
생성 폼에는 없습니다. 같은 테이블을 쓰면서 관리자 쪽만 빠진 비대칭입니다.

결과적으로 공식 비서는 전부 카테고리 없이 한 덩어리로 나옵니다. 비서가 9개인
지금은 괜찮지만 40개가 되면 못 찾습니다.

### 1-2. 없어도 되는 것

**워크스페이스** — 웍스AI는 조직도와 별개인 임시 조직(T/F)용으로 씁니다.
WORKON은 부서 계층(`parent_id`) + `visibility`로 같은 문제를 풉니다. 공공기관은
T/F보다 정규 조직 위계가 지배적이라 개념을 둘로 늘릴 이유가 약합니다.

**결제 카드 관리** — 공공기관은 법인카드가 아니라 연간 예산 집행입니다.
`annual_fixed` 계약이 이 자리를 대신합니다. 카드 등록 화면은 오히려 오해를 부릅니다.

## 2. 사용자 메뉴 대조

| 웍스AI 사용자 | WORKON | 상태 |
|---|---|---|
| AI 대화 — 모델 선택 (40종+) | 단일 모델 고정 | **없음** (알려진 격차) |
| AI 대화 — 새 대화 / 대화 공유(링크 복사·공유 중단) | ✅ 있음 | ✅ |
| AI 대화 — 이미지 생성·저장 | — | 없음 |
| 우리 회사 비서 | 비서 선택 + 카테고리 탭 + 즐겨찾기 | ✅ |
| 나만의 비서 — 이름·역할·아이콘 | ✅ 있음 | ✅ |
| 나만의 비서 — 프롬프트 요술봉 | ✅ 프롬프트 다듬기 | ✅ |
| 나만의 비서 — 능력 토글 3종 | 파일 분석 ✅ / 실시간 검색 **"준비 중"** | **부분** |
| 나만의 비서 — 공식 등록 신청 | ✅ 승인 플로우 | ✅ |
| 앱 설치 (데스크톱·모바일) | 웹 전용 | 없음 |
| — | 내 사용현황 (`/my/stats`) | WORKON 고유 |
| — | 보고서 생성 (`/employee/reports`) | WORKON 고유 |

### 2-1. 즉시 고칠 것: "실시간 검색 능력 — 준비 중"

`CreateAgentModal.tsx`가 실시간 검색을 **"준비 중"으로 비활성 표시**합니다.
그런데 커넥터 4종(법령·KOSIS·나라장터·DART) 7개 도구가 이미 동작하고, 2026-08-19에
실호출 10/10 통과를 확인했습니다. **라벨이 구현보다 뒤처져 있습니다.**

다만 그대로 열면 안 됩니다. 커넥터는 `agents.enabled_connectors`로 **관리자가**
켜는 구조입니다(커넥터 단위 결정은 관리자 몫이라는 설계). 직원이 개인 비서에
임의로 켜면 그 설계가 무너집니다.

→ 기관이 켜 둔 커넥터 안에서만 직원이 고르게 하는 것이 맞습니다.

### 2-2. 모델 선택 — 공공기관에서는 오히려 신중해야 함

웍스AI의 40종 모델 선택은 민간 기준으로는 강점이지만, 공공기관 보안성 검토에서는
**"어떤 모델에 어떤 데이터가 갔는지"를 전부 소명해야 하는 부담**이 됩니다.
`models.ts` 레지스트리와 `usage_logs.details.model` 규약은 이미 다모델 대비가 돼
있으므로, 기능은 준비하되 **기관 관리자가 허용 모델을 제한**하는 형태가 맞습니다.

## 3. 반영 계획

공공기관 대상이라는 전제로 거른 우선순위입니다.

### A. 지금 하는 게 맞는 것 (작고 명확)

| # | 항목 | 근거 | 규모 |
|---|---|---|---|
| A1 | 관리자 공식 비서 폼에 **아이콘·카테고리** 추가 | 컬럼이 이미 있는데 못 씀. 직원 폼과의 비대칭 | 작음 |
| A2 | 비서 **카테고리별 그룹핑 + 노출 순서** | 40개 되면 못 찾음 | 중간 |
| A3 | **실시간 검색 "준비 중" 해제** — 기관이 켠 커넥터 범위 안에서 | 라벨이 구현보다 뒤처짐 | 작음 |

### B. 공공기관 요건상 필요한 것

| # | 항목 | 근거 | 규모 |
|---|---|---|---|
| B1 | **기관 정보** (기관명·로고) + 화면 반영 | CI는 규정 사항. 멀티테넌트인데 브랜딩이 전역 고정 | 중간 |
| B2 | **기관 관리자용 예산 소진 현황** + 경고 배너 | 분기별 집행률 보고가 업무 요건. 0017 인프라는 이미 있음 | 중간 |
| B3 | 이용통계에 **비서별·직원별 축** 추가 | 감사·정보공개 대응 시 요구되는 단면 | 중간 |

### C. 장기 (지금 아님)

- 모델 선택 + 기관별 허용 모델 정책
- SSO (MS Entra ID / 그룹웨어)
- 이미지 생성, 데스크톱 앱

### D. 채택하지 않음

- 워크스페이스 (부서 계층으로 대체)
- 결제 카드 관리 (연간 예산 집행과 맞지 않음)
- 감사 로그·접속 통제의 유료 부가서비스화 (기본 제공이 우리 포지셔닝)

## 4. 대조에서 드러난 WORKON 내부 결함

메뉴를 맞춰 보는 과정에서 확인된, 웍스AI와 무관한 자체 문제입니다.

1. **`agents.category` / `agents.icon`이 관리자 화면에서 쓰이지 않음**
   직원용 폼에만 있고 관리자용에는 없음. 같은 테이블인데 한쪽만 빠짐.

2. **`CreateAgentModal`의 "실시간 검색 준비 중"이 사실과 다름**
   커넥터 4종이 실동작 중.

3. **기관 브랜딩이 전역 단일값(`NEXT_PUBLIC_APP_NAME`)**
   멀티테넌트 제품인데 기관별로 다르게 보여줄 수단이 없음.

4. **`organization_spend_krw`를 기관 관리자가 볼 화면이 없음**
   0017에서 판정 로직만 넣고 조회 화면을 안 만듦.

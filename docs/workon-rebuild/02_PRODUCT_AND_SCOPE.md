# 02. 제품 정의와 범위

## 제품 약속

‘기관이 쓰던 양식에 맞춰 업무 파일을 만들고, 확인할 부분만 고치면 사용할 수 있게 한다.’

파일 직접 생성은 부가 내보내기 버튼이 아니라 업무의 주 결과다. 문서 업무는 HWPX, 취합·계산은 XLSX, 필요하면 검토용 PDF와 첨부 묶음을 제공한다. 실제 파일이 없으면 해당 업무는 완료가 아니다.

## 첫 고객과 운영

기존 서비스 정의의 지방공기업·협회·재단을 첫 고객으로 유지하고, 공공기관 기획·경영지원·사업관리 업무로 확장한다. 연간 정액 계약·사용 한도·기관 운영 구조는 보존한다. 전면 개편을 이유로 종량제·새 모델 사업자·새 워크스페이스 권한 체계를 임의로 추가하지 않는다.

## 10개 공식 업무 비서

고정 키·입력·출력·지원 조건은 `contracts/workflow-catalog.json`을 기준으로 한다. 비서 이름을 바꾸어도 키는 유지한다. 모델 지시문 10개만 추가하는 구현으로 끝내지 않는다. 각 비서는 입력 폼, 단계 처리, 검수 규칙, 실제 파일 산출, 실패·재시도, 평가 사례를 가진다.

| 키 | 이름 | 대표 파일 | 단계 |
|---|---|---|---|
| intake | 접수공문 처리 | 요청사항·처리표 XLSX | B |
| official-letter | 공문 기안 | 공문 HWPX | A |
| report | 보고서·사업계획 | 보고서·요약 HWPX | B |
| collection | 자료 취합·엑셀 정리 | 통합·누락·근거 XLSX | A |
| settlement | 예산·정산 대사 | 대사표 XLSX·정산 HWPX | C |
| regulations | 규정·지침 확인 | 근거 검토 메모 HWPX | A |
| meeting | 회의·위원회 정리 | 회의록 HWPX·후속조치 XLSX | B |
| reply | 민원·문의 회신 | 회신 HWPX | C |
| audit-response | 감사·평가 요구자료 | 답변 HWPX·증빙목록 XLSX | C |
| handover | 인수인계 | 인수인계 HWPX·일정 XLSX | B |

처음부터 상용 지원한다고 표시할 대상은 검증이 끝난 비서뿐이다. 개발 중에는 10개 전체를 설계·구현하되, 실제 제공 가능 상태와 준비 중 상태를 구분한다. ‘준비 중’ 카드 7개와 화면 3개만 만들고 전체 프로젝트가 완료됐다고 보고해서는 안 된다. 최종 상용 관문은 10개 모두 제한된 실제 업무 유형에서 검증되는 것이다.

## 생성과 검토

필수 정보가 있으면 한 번의 ‘파일 만들기’로 생성한다. 없어서는 안 되는 사실이 없으면 어떤 항목이 필요한지 한 화면에 모아 묻는다. 선택 항목은 확인 필요 표시와 함께 초안 파일을 만들 수 있다. 초안·검토 완료·외부 제출은 서로 다른 상태다.

정보 부족·계산 불일치·근거 충돌은 검토 항목으로 제시한다. 직원이 숫자를 임의 수정하면 원본 대사 결과와 연결해서 기록하고, 수정된 값으로 관련 표·본문을 함께 재생성한다. 이미 확정된 다른 영역을 다시 생성하지 않는다.

## 문서 생성 우선순위

1. 기관이 승인한 양식과 버전을 우선한다.
2. 없으면 WORKON이 한글에서 검증한 표준 양식을 사용한다.
3. 원본 양식을 처리할 수 없으면 이유와 대체 양식 차이를 먼저 표시한다. 직원이 대체를 고르면 그 선택을 기록한다.
4. 특정 양식을 못 채운 상태를 ‘완료’로 숨기지 않는다. 원자료와 입력 내용은 보존하고 재시도할 수 있게 한다.

## 성공 지표

작업별: 파일 생성 성공, 직원 검토 후 채택, 복사·표 재작성·서식 수정에 든 시간, 누락·숫자 오류, 반복 실행 실패, 실제 전체 투입시간.

플랫폼별: 완성 업무 수, 과제당 비용, 비서별 실패·재작업, 활성 기관·반복 사용자. 채팅량과 토큰은 운영 지표로 유지하되 업무 성과로 표시하지 않는다. 한 작업을 여러 비서가 처리했다고 절감 시간을 중복 합산하지 않는다.

## 초기 제외

이미지·영상 생성, 음성 녹음 받아쓰기, 노코드 빌더의 전면 노출, 자동 행정처분·지급·계약 확정은 포함하지 않는다. 회의 비서는 메모·전사문부터 처리한다. HWP 이진 형식의 원본 편집을 HWPX 지원과 동일하게 약속하지 않는다.

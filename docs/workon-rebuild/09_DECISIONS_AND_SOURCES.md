# 09. 결정·가정·참고

## 사용자 요구로 확정한 것

- 공공기관 직원의 실제 반복 업무 부담을 줄인다.
- 초기 약 10개 비서의 품질을 높인 뒤 유용한 비서를 하나씩 추가한다.
- 결과를 복사해 한글에 붙여 편집하는 과정을 최소화하고 HWPX 등 파일 자체를 만든다.
- 현 WORKON 서비스를 실행 계획에 맞게 전체적으로 다시 만드는 수준으로 개편할 수 있게 한다.
- 구현은 사용자가 Claude Code로 진행한다.
- 대상 저장소는 `wildkorea8080-netizen/workon`이다.

## 코드 확인을 반영한 권고

- UI·업무 구조는 크게 바꾸고 기존 인증·기관 권한·NODA·LLM 경계·문서·계산 기반은 재사용한다.
- 연간 정액·현재 모델 정책·관리자 체계·메모/전사문 회의 입력은 기존 결정을 유지한다.
- 작업·문서 버전·파일 수명을 대화와 분리한다.
- 개인 업무는 기본 비공개로 두고 기관 공통 규정의 공개 기본값과 구분한다.
- 현재 스택을 유지하고 신규 도메인은 `src/lib/work/` 등의 경계로 분리한다.
- HWPX 정밀 미리보기는 실제 렌더러를 검증한 뒤 제공한다. 텍스트 편집과 임의 HWPX 시각 편집을 구분한다.
- 내구성 있는 실행은 실제로 동작하는 worker·queue·재시도·감시까지 포함한다.

이는 사용자에게 이미 운영 승인된 기술 선택이라는 뜻이 아니다. Claude Code는 현재 환경과 충돌하면 이유를 기록하고 더 단순한 구현으로 조정할 수 있다. 파일 생성·권한·실제 완료 기준은 낮출 수 없다.

## 아직 확인할 것

로그인 이후 운영 화면·운영 DB 적용 상태·Storage 양식·실제 외부 키와 계약·현재 Vercel 플랜·실제 배포 커밋·렌더러와 글꼴 라이선스·한글 호환 검증 환경은 확인하지 않았다. 이 패키지에는 운영 키나 기관 원문이 들어 있지 않다.

## 기존 결정 갱신

| 과거 문서·동작 | 이번 요구로 갱신할 부분 |
|---|---|
| S2 ‘대화 안에서, 최종 손질은 한글에서’ | 작업실 안에서 문단·셀 수정 후 파일 재생성. 파일 밖 재편집량 최소화 |
| 목차·초안·파일 생성 재확인 | 선택한 양식·필수 정보가 있으면 요청 한 번으로 초안 파일 생성 |
| 실패 시 복사 안내 | 파일 실패를 명시하고 입력·편집본을 보존, 작업 재시도 |
| 대화와 생성 파일의 수명 동일 | 기존은 유지, 새 업무 결과물은 독립 수명 |
| 기본 양식 없으면 실제 검사 skip | 개발 테스트와 출시 관문 분리. 출시에서는 기본 양식 준비·실파일 검증 필수 |
| 비서 목록과 채팅 중심 홈 | 10개 업무·작업함·결과물·검토 중심 홈 |

새 제품 정의에서 근거 없는 사실 생성이나 무승인 외부 실행까지 허용하는 것은 아니다. 파일 초안 생성 요청과 대외 발송·제출의 승인을 구분한다.

## 공식 기술 참고

- [한컴 OWPML 모델](https://github.com/hancom-io/hwpx-owpml-model): 문서 요소의 추출·저장 모델과 예제. 완전한 웹 렌더러·편집기가 아님.
- [한컴 DVC](https://github.com/hancom-io/dvc): 허용한 문서 서식에 맞는지 검사하는 예제. 구조 검사와 시각 검증을 분리하는 참고.
- [Vercel 함수 제한](https://vercel.com/docs/functions/limitations): 실행·업로드·응답·메모리 제약을 현재 플랜에서 재확인.
- [Vercel 2026-06-15 변경 안내](https://vercel.com/changelog/vercel-functions-can-now-run-up-to-30-minutes): 일부 실행 시간 조건이 변했으므로 오래된 문서의 고정 숫자만 믿지 않음. 이 설계는 특정 시간값을 전제로 하지 않음.
- [PostgreSQL 행 보안 정책](https://www.postgresql.org/docs/17/ddl-rowsecurity.html): 정책과 우회 권한·소유자 동작을 확인. 현재 Supabase service role의 서버 필터를 대체하는 보증으로 사용하지 않음.
- [NIA 2026 공공부문 AI 도입 가이드 안내](https://www.nia.or.kr/site/nia_kor/ex/bbs/View.do?bcIdx=29526&cbIdx=37989): 기관의 공통기반·도입 절차 검토.

경쟁사·서비스 전략의 상세 근거는 패키지에 포함한 [서비스 실행 계획](references/strategy-plan.md)을 참고한다. 구현은 현재 저장소 코드와 본 패키지의 지원 범위를 기준으로 한다.

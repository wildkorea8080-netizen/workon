# 현행화 가상 사례 (S6-1)

**실제 기관 문서가 아니다.** 현행화 엔진을 만드는 동안 쓰는 가상 2025년 사업계획이다. 파일은 저장소에 두지 않는다 — 시험과 점검 스크립트가 실행할 때마다 만든다.

- 시험: `tests/helpers/prior-fixture.ts`(`priorFixture`) — 표준 보고서 양식 `assets/templates/report.hwpx`를 실제 채우기 엔진(`readFillableTemplate` + `fieldsFromSlots` + `generateDocumentFile`)으로 채운다. 표·문단을 덧붙일 때는 `appendXml`(`tests/fixtures/hwpx.ts`의 `para`·`tableAt`)
- 실제 모델 점검: `scripts/work-llm-smoke.mjs`의 `currentize` 사례(`npm run work:llm-smoke -- --yes-cost --only currentize`). 기록은 `evidence/llm-smoke-2026-10-28-currentize.md`

## 가상 작년 파일 (`prior`, HWPX)

| 자리 | 글 |
|---|---|
| 제목 | `2025년 ○○ 사업계획` |
| 개요 | `2025년에는 사업 A·B를 추진하였다.` |
| 주요 내용 1문단 | `2025년 예산은 1,200백만원이다. 「지방공기업법」 제64조에 따라 편성한다. 담당 부서는 기획팀이다.` |
| 주요 내용 2문단(점검 스크립트만) | `사업 B를 계속 추진하여 지역 일자리를 늘린다.` — 연도·수치·인용이 없는 줄글이라야 모델이 고친다 |
| 표(점검 스크립트만, 문서 끝) | 위에 `(단위: 백만원)` 문단, 머리글 `구분 / 2024년 / 2025년 / 증감`, 행 `사업 A / 1,100 / 1,200 / 100` |

## 올해 자료

| 용도 | 파일 | 내용 |
|---|---|---|
| `data` | `2026 예산.xlsx` | 시트 `2026 예산` — `구분 / 2026년`, `사업 A / 1300` |
| `reference` | `2026년 사업 방향.txt` | `2026년에는 사업 B를 중단하고 사업 C를 새로 시작한다. 예산은 1,300백만원으로 늘린다.` |
| 작업 입력(`emphasis`, 메모) | — | `사업 B 중단, 사업 C 신설` |

작업 입력은 보고서 `reportType`(`사업계획`)·`period`(`2026년`)이다. 기준일은 오늘(점검 날짜의 연도 → 올해 2026).

## 바뀌어야 하는 것

| 대상 | 기대 | 누가 |
|---|---|---|
| 제목·개요·주요 내용의 `2025년` | `2026년` — 상태 `바꿈`(`year`) | 프로그램 |
| 표 머리글 `2024년`·`2025년` | `2025년`·`2026년` | 프로그램 |
| 표 `사업 A` 행 | 2024열 칸 `1,100` → `1,200`, 2025열 칸 `1,200` → `1,300`(올해 자료 표에서). 증감은 다시 계산하는데 1,300 − 1,200 = 100이라 값이 같아 변경 없음. 단위를 한쪽이라도 알 수 없으면(점검에서는 올해 자료 표에 단위가 없어 이 경우였다) 그대로 넣되 `확인 필요`로 | 프로그램 |
| 줄글 `1,200백만원` | 올해 자료·메모에서 확인되지 않은 숫자 → `확인 필요`(`number`). 본문 수치는 프로그램도 모델도 바꾸지 않는다 | 프로그램이 표시 |
| `「지방공기업법」 제64조` | 현재 조문과 대조(`citation`). 점검 스크립트는 근거 제공자를 쓰지 않아 `현재 조문을 찾지 못함` → `확인 필요` | 프로그램이 표시 |
| `사업 B를 계속 추진하여…` | 메모·방향 문서에 근거해 모델이 다시 씀: `사업 B를 중단하고 사업 C를 새로 추진하여…` — 근거(`basis`)가 맞으면 `바꿈`, 아니면 `제안`(파일에는 안 들어감) | 모델(글 수준만) |

점검 스크립트가 찍는 줄: 변경 수(바꿈 / 확인 필요 / 제안), `costStopped`, 결과 HWPX 안에 `2026년 ○○ 사업계획`이 있는지(`readSegments`로 읽어 봄).

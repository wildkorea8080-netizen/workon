# WORKON 전면 개편 — Claude Code 실행 패키지

작성: 2026-10-26 · 대상 저장소: https://github.com/wildkorea8080-netizen/workon

분석 기준 커밋: `702cc436b895c278ba1fc6eb13673e88d07c3091`

## 목표

WORKON을 **기관 양식에 맞는 HWPX·XLSX 결과 파일을 만들고 서비스 안에서 검토·수정하는 업무 플랫폼**으로 개편한다. 직원의 주 흐름은 업무 선택 → 자료·양식 → 생성 → 검토·수정 → 파일 다운로드다. 채팅은 문서 수정·추가 설명을 돕는 보조 수단이다.

화면·업무 구조는 전면 개편하되, 검토 결과 재사용할 수 있는 기존 인증·기관 권한·NODA·문서 채우기·표 계산·과금·감사 기반은 보존한다. 새 언어모델이나 문서 SaaS, 새 결제 체계를 도입하는 요구가 아니다.

## 사용자 결정과 기존 문서의 관계

2026-10-26 사용자는 초기 약 10개 비서와 결과 파일 직접 생성, 복사·붙여넣기·한글 재편집의 최소화, 실행 계획에 맞는 전면 개편을 요청했다. 따라서 기존 S2의 ‘대화 안에서 목차 확인 → 초안 → 최종 손질은 한글에서’, ‘별도 작성 화면은 나중’이라는 제품 결정은 이번 요구로 갱신한다.

그 밖의 기존 보안·환경변수·LLM 경계·기관 격리·과금 기록 규약은 유지한다. 기존 `CLAUDE.md`를 무조건 지우거나 이 문서로 덮어쓰지 말고, 변경된 제품 결정과 새 코드 경로를 반영해 갱신한다. 분석 커밋 이후 변경이 있으면 현재 코드를 먼저 비교한다.

## 사용법

1. 실제 WORKON 저장소를 Claude Code에서 연다.
2. 이 `workon-rebuild` 폴더를 저장소의 `docs/workon-rebuild/`로 복사한다. 기존 소스나 `.env`를 이 패키지로 대체하지 않는다.
3. `10_CLAUDE_CODE_START.md`의 시작 지시문을 Claude Code에 전달한다.
4. Claude Code는 코드 확인 후 P0부터 구현을 시작하고 단계별 장부를 남긴다. 한 번에 전체 완료를 주장하거나 화면만 만든 뒤 완료 처리하지 않는다.
5. 새 세션에서는 시작 문서에 있는 ‘이어 하기’ 지시문으로 재개한다.

## 패키지의 범위

이 패키지는 코드 분석을 반영한 구현 명세·작업 지시문이다. 서비스 구현·운영 DB 변경·실제 파일 생성·한글 호환 검증이 완료된 산출물이 아니다. 새 HWPX 양식 바이너리와 미리보기 변환기 라이선스는 포함하지 않는다. 코드 조사와 문서 계약 검증을 수행했으며 기존 저장소의 테스트 전체를 실행한 것은 아니다.

`01_CURRENT_CODE_AUDIT.md`의 기존 기능은 코드 존재를 확인한 것이다. 운영 환경의 키·DB·배포 파일·품질까지 확인한 것은 아니다. 확인하지 못한 항목은 완료로 표시하지 않는다.

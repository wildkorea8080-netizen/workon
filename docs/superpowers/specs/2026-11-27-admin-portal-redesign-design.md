# 관리자 포털 디자인을 직원 화면에 맞추기 — 짧은 설계

2026-11-27, 사용자 승인("이대로 해 주세요").

## 의도
관리자 포털(`/admin/**`)이 직원 화면(업무 틀 `WorkShell`)과 다른 제품처럼 보인다 — 짙은 남색 사이드바·흰 판 로고·박힌 남색(`#003087`)·파란색, 좁은 화면 처리 없음, 기관 테마 색(0067)을 따르지 않음. 직원 화면처럼 세련되게, 같은 제품으로 보이게 한다.

## 목표
1. **틀**: `src/app/admin/layout.tsx` 사이드바를 직원 화면과 같은 밝은 사이드바로 — 로고 위(흰 판 없이), 메뉴 12개(지금 아이콘 그대로), 고른 메뉴는 기관 테마 색(`ws-*`), 아래 사용자 정보·'업무 화면으로', 사이드바 접기(직원 화면과 같은 기억 `sidebar-pref`), 작은 화면은 위쪽 가로 탭. 대리 접근 띠는 그대로. 기관 테마 색은 서버가 읽어 `themeStyle`로 첫 그림부터.
2. **안쪽 화면**: `src/app/admin/**`·`src/components/admin/**`의 박힌 남색·파란 강조색(단추·탭·도는 표시·선택 표시)을 `ws-accent` 계열로. 바탕·글꼴은 직원 화면과 같게(`#F7F8FC`, Pretendard). 각 화면의 배치·내용은 그대로.
3. **재발 막기**: 관리자 화면 파일에 `#003087`·`[#1C2B4A]`를 직접 적으면 시험이 막는다(`tests/theme-color.test.ts`와 같은 방식).

## 하지 않음
슈퍼관리자 포털·로그인 화면·관리자 화면 구성 변경. 상태 색(빨강 오류·초록 성공·주황 경고·보라 '관리자' 표시)은 뜻이 있는 색이라 그대로.

## 방법
하나뿐 — 직원 화면의 틀·색 체계(`ws-*` CSS 변수, `themeStyle`)를 관리자 틀에 그대로 쓴다. 다른 길(관리자 전용 새 색 체계, 관리자 화면을 `WorkShell` 안에 넣기)은 버림: 새 체계는 두 화면이 다시 갈라지고, `WorkShell` 안에 넣으면 직원 메뉴와 관리자 메뉴가 한 사이드바에 섞인다.

## 만드는 사람에게 맡김
사이드바 세부 간격·아이콘 크기, 파란색 중 강조가 아닌 정보 색(예: 파란 안내 상자)을 테마 색으로 바꿀지 — 강조(단추·선택·링크)만 바꾸고 안내 상자는 연한 테마 색으로.

# 지방공기업 기본 앱 세트 — 짧은 설계

2026-11-27, 사용자 승인("이대로 만들어 주세요").

## 의도
첫 고객으로 시설관리공단 같은 지방공기업이 유력하다. 지금 기본 비서·앱 세트는 공공기관 공통 업무뿐이라, 지방공기업 직원이 들어와 "우리 일"을 바로 보게 한다. 깊이보다 넓이 — 실제로 많이 쓰는 앱을 본 뒤 하나를 깊게 판다(경영평가 등).

## 목표
입력형 앱 5개(`LOCAL_PUBLIC_ENTERPRISE_PRESETS`, 범주 '지방공기업'):
1. 경영평가 실적 문안 — 지표·올해/작년 실적·강조점 → 지표별 실적 문안, 넣은 숫자만, 증빙 목록, [확인 필요]
2. 계약 방법 검토 — 대상·구분·추정가격·특수 사정 → 법령 조회 단계(지방계약법 시행령) → 계약 방법·근거 조문·확인할 점 (커넥터 `law`)
3. 위험성평가·안전점검 정리 — 시설·작업/점검 내용·발견 사항 → 위험 요인·위험성·감소 대책·중대재해처벌법상 챙길 일
4. 시설 이용 민원 답변 — 민원·시설·처리 결과/관련 규정 → 답변 초안·다음 절차
5. 이사회 안건 작성 — 안건명·제안 이유·주요 내용·관련 규정 → 안건서 초안(제안 이유·주요 내용·참고 사항)

설치: 기관 유형이 '지방공기업'일 때만 `presetsForOrganizationType`이 더한다 → 기관 등록 자동 설치·관리자 '기본 비서·앱 세트'·`seed:agents`가 함께 따른다.

## 지키는 것
기존 기본 앱과 같다 — 입력·조회 결과에 없는 숫자·조문·날짜를 만들지 않고 [확인 필요], 법 위반을 단정하지 않음. 정의는 `validateAppDefinition` 통과, 조회 단계를 쓰는 앱만 `connectors`.

## 하지 않음
경영평가 깊게(작년 보고서 현행화·증빙 확인), 공통 자료실 문서 올리기, 다른 기관 유형에 깔기.

## 방법(사용자 선택)
1 넓게 기본 세트(고름) / 2 경영평가 깊게 / 3 기준 문서만 — 첫 고객이 무엇을 많이 쓸지 몰라 넓게 깔고 쓰임을 본 뒤 깊게.
